# 12. Backpressure

Защита от бесконечного роста очереди: производитель притормаживается до
скорости самого медленного звена.

## Задача

Быстрый producer шлёт задачи быстрее, чем медленный consumer успевает
обрабатывать. Если очередь не ограничена — она растёт бесконечно и память
кончается.

## Как работает

- SysV-очередь ограничена ядром (`msg_qbytes`).
- Когда очередь полна, `msg_send` **блокируется** — producer вынужден ждать,
  пока consumer освободит место.
- Так producer "притормаживается" до скорости самого медленного звена —
  стратегия **block**.
- Альтернативы (не в этом уроке): drop (терять новые), error (падать),
  bounded queue в user-space с `if (stat.qnum >= LIMIT) { ... }`.

## IPC

System V очередь; `msg_stat_queue` для наблюдения за заполненностью.

## Паттерн

**Backpressure / Bounded Buffer** — ограничение буфера как механизм
регулировки скорости.

## Запуск

```bash
docker compose exec -T php php /app/12_backpressure/main.php
```

## Что попробовать изменить

- Ускорить/замедлить consumer (`usleep`) — увидеть, как меняется заполнение.
- Добавить вывод `msg_stat_queue()['msg_qnum']` в каждый цикл producer'а.
- Реализовать стратегию drop: `msg_send(..., MSG_NOERROR)` + проверка полноты.

## Real world

TCP (window), bounded queues в RabbitMQ/кафке (retention), каналы Go
(буферизованные).
