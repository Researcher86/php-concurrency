Mini PHP Runtime (мини-рантайм, итог курса)
                 ┌─────────────────┐
                 │     Server      │
                 │  приём запросов │
                 └───────┬─────────┘
                         │
                 ┌───────▼─────────┐
                 │ Master Process  │
                 │  форкает пул    │
                 └───┬────┬───────┬┘
                     │    │       │
              ┌──────▼┐ ┌▼─────┐ ┌▼─────┐
              │Worker │ │Worker│ │Worker│
              └───────┘ └──────┘ └──────┘
                     │    │    │
                     └────┼────┘
                          │
                      IPC/Queue
                           │
                 Polling Loop (опрос)
                 MSG_IPC_NOWAIT + WNOHANG
                           │
                      Supervisor

   Всё, что было в 01–32, сходится в одну маленькую модель
   PHP-FPM/RoadRunner: master + пул persistent-воркеров +
   очередь задач + цикл обработки + перезапуск упавших.

   Важно: очередь SysV — не fd, поэтому master ОПРАШИВАЕТ её
   (polling), а не ждёт событий через select/epoll.
