# 14. Actor Model

Изолированные акторы-процессы, общающиеся только сообщениями.

## Задача

Разбить систему на акторы: каждый — изолированный процесс со своим состоянием
и mailbox'ом (отдельная SysV-очередь). Общение ТОЛЬКО через сообщения,
общего состояния нет.

## Как работает

- Каждый актор — процесс со своим mailbox (своя очередь).
- Акторы общаются, отправляя сообщения в mailbox друг друга.
- Mailbox буферизует сообщения: можно отправить ещё не существующему актору.
- Актор может спавнить дочерних акторов (Actor B спавнит Actor C).

## IPC

System V очереди: одна на актора (mailbox). Прямой связи между акторами нет —
только через очереди.

## Паттерн

**Actor Model** — изоляция состояния + асинхронные сообщения
(Erlang/OTP, Akka).

## Запуск

```bash
docker compose exec -T php php /app/14_actor_model/main.php
```

## Что попробовать изменить

- Добавить ещё один актор и переслать ему сообщение.
- Сделать актор, который спавнит актора при получении определённого сообщения.
- Добавить ассинхронный таймаут на ожидание ответа от mailbox.

## Real world

Erlang/OTP, Akka (JVM), Orleans (C#), мессенджеры с per-user inbox'ами.
