Actor Model (акторная модель)
   ┌──────────────────────────────────────┐
   │  Actor A                             │
   │  ┌────────────────────────────────┐  │
   │  │  mailbox                       │  │
   │  │  [msg1][msg2][msg3]            │  │
   │  └─────────────┬──────────────────┘  │
   │                │ handle              │
   │  state: {counter: 42}                │
   │  behavior: receive(msg) -> action    │
   └────────────┬─────────────────────────┘
                │ send(msg)
                ▼
   ┌──────────────────────────────────────┐
   │  Actor B                             │
   │  ┌────────────────────────────────┐  │
   │  │  mailbox                       │  │
   │  │  [msg from A][msg from C]      │  │
   │  └─────────────┬──────────────────┘  │
   │                │ handle              │
   │  state: {items: [...]}               │
   └──────────────────────────────────────┘
                │
                │ spawn child
                ▼
   ┌──────────────────┐
   │  Actor C         │
   │  ┌────────────┐  │
   │  │  mailbox   │  │
   │  └────────────┘  │
   │  ...             │
   └──────────────────┘

   * Each actor is isolated
   * Communication only via messages
   * No shared state

─────────────────────────────────────────
Сложность: ⭐⭐⭐⭐
Syscalls:  fork(), msgget(), msgsnd(), msgrcv(), msgctl(), waitpid()
Real world: Erlang/OTP, Akka, Orleans (.NET), amphp/parallel
