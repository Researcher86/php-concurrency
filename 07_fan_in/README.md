# 07. Fan-In

Сборка результатов от многих воркеров в одном месте.

## Задача

N воркеров параллельно считают, родитель собирает их результаты. Обратная
сторона fan-out.

## Как работает

- Воркеры пишут результат в общую shared memory.
- Родитель после завершения воркеров читает собранные значения.
- ВАЖНО: shared memory сама по себе не синхронизирует — здесь порядок чтения
  простой (сначала все воркеры закончили, потом читаем). Для атомарности
  счётчика/записи нужен семафор (см. 02, 27, 28).

## IPC

Shared memory (`shm_attach`/`shm_put_var`/`shm_get_var`). Константы вынесены
на верхний уровень.

## Паттерн

**Fan-In** (веерная сборка).

## Запуск

```bash
docker compose exec -T php php /app/07_fan_in/main.php
```

## Что попробовать изменить

- Писать в shm не после завершения, а во время работы воркеров, и читать
  до `waitpid` — увидите гонку.
- Добавить семафор вокруг записи в shm — распределение станет честнее.

## Real world

Агрегация метрик, результаты поиска от нескольких шардов.
