Work Stealing (кража задач)
   Мастер раздаёт неравномерно: W1 перегружен, W2/W3 почти свободны

   ┌────────────┐
   │ Master     │  6 задач │ 2 задачи │ 1 задача
   └─┬────┬────┬┘
     │    │    │
   ┌─▼─┐┌─▼──┐┌▼───┐
   │ W1││ W2 ││ W3 │   свободные воркеры крадут
   │▶▶▶││idle││idle│◄─ задачи из чужих очередей
   └───┘└────┘└────┘

   Итог: работа балансируется автоматически,
   все воркеры заканчивают примерно одновременно

─────────────────────────────────────────

Syscalls:  fork(), msgget(), msgsnd(), msgrcv(), msgctl(), usleep()
Real world: Go runtime scheduler, Java ForkJoinPool, Ray, Celery
