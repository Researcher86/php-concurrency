   ┌────────────┐  events   ┌──────────────────────────┐
   │ Source 1   ├──────────►│                          │
   │ Source 2   ├──────────►│  stream_select()         │
   │ Source 3   ├──────────►│  один цикл ждёт событий  │
   └────────────┘           │  на ВСЕХ каналах сразу   │
