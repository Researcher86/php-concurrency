Worker Pool (pool of workers)

Реализация: мастер создаёт пул воркеров, все читают одну SysV-очередь задач.
«Результат» в этой версии — просто echo в общий stdout (нет отдельного канала результатов).

       ┌─────────────────────────────┐
       │         Task Queue          │
       │   [T1][T2][T3]...[T50]      │   SysV msg queue (msg_get_queue)
       └──────────────┬──────────────┘
                      │ dispatch
                      │ msg_receive MSG_IPC_NOWAIT (poll 10ms)
          ┌───────────┴───────────┐
          │       │       │       │
          ├───────┼───────┼───────┤
       ┌──▼───┐┌──▼───┐┌──▼───┐┌──▼───┐
       │  W1  ││  W2  ││  W3  ││  W6  │
       │ done ││ done ││ done ││ done │
       └──────┘└──────┘└──────┘└──────┘
          │       │        │       │
          └───────┴────────┴───────┘
                       │
              ┌────────▼────────┐
              │   stdout (echo) │   общий консольный вывод всех процессов
              │  (не результат) │   (мастер + воркеры пишут в один stdout)
              └─────────────────┘

Примечание: «Results Channel» из абстрактной схемы здесь не реализован.
Реальный канал результатов = вторая очередь/коллектор, куда воркеры
складывали бы итог (см. уроки 09/10 — fan-out / fan-in). В этой версии
результата нет — задачи просто потребляются, вывод = лог в консоль.
