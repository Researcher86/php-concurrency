# 18. Scheduler

Планировщик раздаёт задачи по воркерам round-robin — по кругу.

## Задача

Мастер сам решает, какому воркеру достанется задача, а не отдаёт на
конкуренцию (в отличие от fan-out 06).

## Как работает

- Мастер получает задачи из очереди.
- Раздача по политике **round-robin**: каждому следующему воркеру по кругу
  (W1 → W2 → W3 → W1 → ...).
- Детерминированное распределение: зная номер задачи, можно предсказать
  воркера.

## IPC

System V очереди; `pcntl_waitpid`; `pcntl_fork()` с проверкой на -1.

## Паттерн

**Scheduler / Load Balancer (round-robin)** — планирование вместо конкуренции.

## Запуск

```bash
docker compose exec -T php php /app/18_scheduler/main.php
```

## Что попробовать изменить

- Сменить политику: least-loaded (воркеру с наименьшей очередью) или weighted.
- Добавить задаче id и выводить его с именем воркера.
- Сравнить распределение с 06_fan_out на одинаковых данных.

## Real world

nginx (upstream round-robin), Kubernetes scheduler, RabbitMQ consistent hash.
