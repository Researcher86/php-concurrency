# 06. Fan-Out

Раздача одной задачей множеству воркеров: каждый берёт следующую свободную.

## Задача

Распараллелить обработку набора задач: N воркеров разбирают общую очередь,
каждый берёт очередную задачу (competing consumers).

## Как работает

- Source-процесс (или мастер) закидывает задачи в общую очередь.
- N воркеров конкурируют за очередь: каждый забирает следующую свободную задачу.
- Распределение не детерминированное — кто успел, тот и взял (в отличие от
  scheduler'а из 18, где мастер сам решает кому дать).

## IPC

System V очередь; проверка `pcntl_fork() === -1` после каждого форка;
`pcntl_waitpid` для сбора.

## Паттерн

**Fan-Out** (веерная раздача) поверх competing consumers.

## Запуск

```bash
docker compose exec -T php php /app/06_fan_out/main.php
```

## Что попробовать изменить

- Менять число воркеров и объём задач — смотреть на время выполнения.
- Сделать воркеров больше задач — кто-то не получит ничего (или очередь пуста).
- Добавить номер задачи в вывод — увидеть, кто какую взял.

## Real world

Обработка изображений, рассылки, MapReduce (фаза map).
