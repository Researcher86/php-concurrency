Mini Messenger (мини-мессенджер)
    ┌────────────┐         ┌────────────┐
    │   Client   │         │   Client   │
    │   User A   │         │   User B   │
    └──────┬─────┘         └─────▲──────┘
           │                     │
           │ send(msg)           │ receive
           │                     │
           ▼                     │
   ┌────────────────────────────────────┐
   │          Message Broker            │
   │  ┌──────────────────────────────┐  │
   │  │  Chat Room: general          │  │
   │  │  [msg1] [msg2]               │  │
   │  ├──────────────────────────────┤  │
   │  │  Chat Room: random           │  │
   │  │  [msg3]                      │  │
   │  ├──────────────────────────────┤  │
   │  │  Direct: A -> B              │  │
   │  │  [msg4]                      │  │
   │  └──────────────────────────────┘  │
   │  dispatch ──> broadcast            │
   └────────────────────────────────────┘
