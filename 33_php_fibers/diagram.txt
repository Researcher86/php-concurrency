Fiber (кооперативная приостановка выполнения)

   main()
     │
     ├─ $fiber->start() ───────────► fiber: { ... }
     │                                  │
     │                                  ├─ код до suspend() — выполняется сразу
     │                                  ├─ Fiber::suspend('paused')
     │                                  │    ↓ (управление вернулось в main)
     │  start() вернул 'paused'         │
     │                                  │
     ├─ $fiber->resume('hello') ───────►│  suspend() вернул 'hello'
     │                                  ├─ код после suspend() — выполняется сразу
     │                                  └─ return 'fiber-done' (terminated)
     │
     └─ $fiber->getReturn() === 'fiber-done'

   Важно:
   - Один процесс, один поток, одна стек-рамка выполнения.
   - Переключение ТОЛЬКО в точках suspend()/resume() — кооперативно.
   - Никакого параллелизма: пока фибра крутит цикл, main не выполняется.
   - Общие переменные — напрямую, IPC не нужен (это тот же процесс!).

   Состояния: not started -> started/suspended -> running -> terminated

─────────────────────────────────────────
Сложность: ⭐⭐⭐ — простой механизм, но к нему надо привыкнуть
Syscalls:  нет системных вызовов (чистый userland, без fork/select)
Real world: Amp v3, Revolt (фиберы поверх event loop), PHP 8.1+
