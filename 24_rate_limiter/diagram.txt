Rate Limiter (ограничитель скорости)
   Задачи (без ограничений)
        │
        ▼
   ┌────────────┐
   │  Token     │   R воркеров разделяют ОДИН лимит
   │  Bucket    │   (например 100 задач/сек)
   │  (shm)     │
   └─────┬──────┘
         │ берут токены под семафором
         ▼
   ┌─────┴────────────┐
   │  Worker 1 2 ... R│   суммарно не быстрее лимита
   └──────────────────┘

   Память/семафор общие: лимит соблюдается по всем воркерам сразу,
   а не по каждому отдельно.

─────────────────────────────────────────
Сложность: ⭐⭐⭐
Syscalls:  fork(), semget(), semop(), shmget(), shmat(), shmdt(), usleep()
Real world: API gateways, nginx limit_req, Redis token bucket, rate-limit алгоритмы
