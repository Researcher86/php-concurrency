Mini RoadRunner (приложение-сервер)
   ┌──────────────┐  jobs  ┌────────────────────────┐
   │    Server    │ ──────►│ Worker 1 (persistent)  │
   │   (мастер)   │ ◄──────│ цикл: job → result     │
   │              │        └────────────────────────┘
   │              │  jobs  ┌────────────────────────┐
   │              │ ──────►│ Worker 2 (persistent)  │
   │              │ ◄──────│ crash → restart        │
   └──────────────┘        └────────────────────────┘

   Воркеры ЖИВУТ между запросами (в отличие от
   классического PHP, где процесс умирает после запроса).
   Общение через relay-канал (pipe), как в RoadRunner.
